# 台湾旅行のしおり

家族で行く台湾旅行の「準備リスト」「もちものチェックリスト」「旅程」をまとめた静的サイトです。
ビルドは不要で、HTML・CSS・JavaScript だけでできています。

| ページ | ファイル | 内容 |
| --- | --- | --- |
| ホーム | `index.html` | 旅の基本情報(日程・便・ホテル)と、現地の連絡先 |
| 準備リスト | `prep.html` | 出発までにやることを、時期ごとにチェック |
| もちものチェックリスト | `packing.html` | 荷造りのチェックリスト |
| 旅程 | `itinerary.html` | 日ごとの流れ(訪問先には地図へのリンク付き) |

## 見かた

- パソコンで確認する: `index.html` をブラウザで開きます。または、このフォルダで `python3 -m http.server` を実行して http://localhost:8000 を開きます。
- 家族に見せる: GitHub の Settings → Pages で、公開するブランチとフォルダ `/ (root)` を選ぶと、URL で見られるようになります。

## 直しかた

- 黄色い「未定」の表示(`class="tbd"`)は、まだ決まっていない項目です。決まったら書き換えます。`tbd` で検索すると、残りを探せます。
- 旅程は、`itinerary.html` の `<section class="day ...">` が1日分です。コピーして日数を増減できます。`<li class="stop">` が1か所分です。
- チェックリストは、`<li>` が1項目分です。項目名を書き換えると、その項目のチェックは外れます。
- 色や文字の大きさは、`assets/style.css` の先頭にある変数で変えられます。

## 注意

- チェックの状態は、見ている端末のブラウザにだけ保存されます。家族の端末とは共有されません。
- 日程やホテル名を書き込んで公開すると、URL を知っている人には見えます。留守にする日を書くときは、公開範囲に気をつけてください。
- 準備リストにある制度の情報(入国カード、持ち込みルールなど)は、2026年9月に調べた内容です。出発前に、公式サイトで最新の情報を確認してください。
